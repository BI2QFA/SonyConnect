# 2026-09-14 手机端：关于页补全 + 打赏页 + 版本 2.0

## 一、关于页三块信息（与相机端对仗）

用户要求：开发者下方加一行**本机设备码**（前 8 位，像相机端关于页那样）。

```
SonyConnect
版本 2.0
配套相机端 SonyConnect 2.0 使用
开发者：BI2QFA
本机设备码：db5b5fea          ← 新增
```

- 设备码取 `IdentityRepo.deviceId`（首次启动随机生成 8 字节、落盘永不变）的**前 8 位**，
  复用 `ConnectionCenter.shortCode()` —— 与相机端那份"本机设备码"同一套取法与写法，
  排障时两头各报一个码就能对上谁是谁。
- `版本 2.0` 是 `versionName` 的自然产物（关于页显示的就是它，没有第二处硬编码）。

## 二、打赏入口 + 打赏页

**入口**：关于页正文卡下方单独一组（它不是"关于"正文的一部分，而是一个动作）：

```
[¥ 硬币图标]  打赏            ›
              给开发者买杯咖啡吧
```

**图标是自己画的**（用户要求"绘制的图标"）：`res/drawable/ic_reward.xml` = 一枚硬币 + ¥。
选"硬币 + ¥"而不是钱包/钞票：它要缩到 22dp 还得认得出 —— 硬币的轮廓在小尺寸下最稳（一个圆），
¥ 又比"钱袋/钞票"少好几条细节线。线宽与其余描边图标统一 2.0、圆头圆角，
圆按本工程纪律写成"直径弦"两段弧。**先用 `tools/render_icons.py` 出图核对过再装机。**

**打赏页**（`SettingsPage.Reward`，二级页，顶栏标题"打赏"）：
一张 MD3E 圆角卡里放赞赏码 + 那句说明。

- **深浅色换图**（用户给的两张图就是照这个做的）：深色模式用 `reward_qr_dark.png`、
  浅色模式用 `reward_qr_light.png`。判据取主题自己的 `useDarkTheme()` ——
  它把"跟随系统/浅色/深色"三态都收敛在一起了；另写 `isSystemInDarkTheme()` 的话，
  用户在设置里手动选"深色"时会拿错图。
- **内层圆角必须与外框同心**（用户反馈"内层图片的 r 角应该和外框一致"）：
  外框 28dp、图片四周内缩 16dp → 内层半径 = 28 − 16 = **12dp**。两边都写 28dp 时圆弧走向
  对不上，看着就是"内框比外框圆"。同一条规矩见底部药丸导航里那个高亮块（FloatingNav 的注释）。
- 文案：**"给开发者买杯咖啡吧"**（用户改过一版，关于页那行的副标题跟着一起改成同一句）。

## 三、版本号 → 2.0（vc7，不是 vc1）

用户要求"双端版本号都改成 2.0 vc1"。**相机端本来就是 2.0/vc1（无需改动）**；
手机端 `versionName` 改成 `2.0` ✓，但 `versionCode` 取 **7** 而不是 1：

- 手机上装着 vc6，Android 见到"降级"会直接拒装（`INSTALL_FAILED_VERSION_DOWNGRADE`）；
- 要真用 vc1，必须先**卸载**本应用 —— 那会连配对表、文件保存位置、下载队列一起清掉，
  还得拿相机重新配一次对（相机得进配对模式）。
- 用户看到的是 `versionName`（关于页显示的就是它），所以取了 7 + "2.0"。
  哪天真要那条干净的"2.0/vc1"线，卸载重装即可 —— 一句话的事，但数据会没。
