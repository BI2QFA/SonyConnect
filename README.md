# SonyConnect

## 介绍

为索尼老机型提供更好更方便的连接手机功能

## 功能

- 通过连接已有Wi-Fi或创建Wi-Fi热点连接手机
- 传输SD卡内的文件
- 智能的缩略图解析机制

## 更新

- 2.6
  - 传输提速：批量流式传输（一条数据连接连传多张 + 向前看解析 + JPG 尾扫描提速）、小缩略图并发拉取
  - 相机端批量解图与预取（2 条常驻 worker + 微批），缩略图与预览图不再互相排队
  - 新增"自动传输预览图"：连接后自动把缩略图与大预览一起拉到手机，并持久缓存（容量可在设置里调整）
  - 文件页选择模式下双击进大图预览（单击零延迟）；大图按 EXIF 方向自动转正，小缩略图同步跟转
  - 大预览携带 EXIF：文件页与传输页共用"照片信息"弹窗
  - 修复：重启后小图缓存被整轮重拉、预览缓存上限在多相机下翻倍、开始传输前未预检下载目录

- 2.5
  - 修复了一些影响使用的 BUG
  - 小改了配对流程
  - 修改了手机端的界面，使之更符合 Material 3 Expressive 规范
  - 现在单击文件可以打开大图预览界面，支持了左右横滑切换照片和在预览界面选中文件，方便选片

- 2.0
  - 底层彻底重构，完全重写了控制协议和传输协议，不再使用低效率的FTP进行文件传输
  - 增加了配对模式和更好的设备记忆机制
  - 相机端完整实现了索尼原厂软件的界面框架与外观
  - 手机端使用了 Material 3 Expressive 设计语言

- 1.0
  - 首个版本

## 兼容性

理论上支持所有可安装APK程序的索尼相机，仅在A6300 FW2.01上测试完整功能可用，其他机型不保证能使用全部功能

## 使用方法

使用[Sony-PMCA-RE](https://github.com/ma1co/Sony-PMCA-RE)将SonyConnect-Camera-2.6.apk安装至相机
将SonyConnect-Phone-2.6.apk安装至手机
使相机与手机处于同一局域网下即可连接
