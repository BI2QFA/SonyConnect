### 4.3 加密与认证（照抄，双端逐字节一致）

- **套件**：AES-128-CBC + HMAC-SHA256，**Encrypt-then-MAC**（GCM 实测可用但不用，仅作 `cryptoSuite` 备选位）
- **会话密钥**：`K = HMAC(psk, "SonyConnect-session-v1" ‖ nA ‖ nC)`（**nA 在前、nC 在后**）
- **数据帧**：`Length(4)|Type(4)|TxId(4)|Seq(8)|Ciphertext(N)|MAC(32)`
  - `IV = sessionSalt(8) ‖ Seq(8)`（每帧唯一，杜绝 CBC IV 重用）
  - `MAC = HMAC-SHA256(K_mac, Length‖Type‖TxId‖Seq‖Ciphertext)`；AAD = 前 12 字节
  - `ENC_HDR_LEN=12`、`HEADER_LEN=8`、MAC_LEN=32、IV_LEN=16、明文 CHUNK=64 KiB
  - Seq 单调递增，接收端拒绝非递增 → 抗重放内建
- **双向认证握手（全程明文，`PtpIpServer.authenticate`）**：
  1. 相机→手机 `OP_AUTH_CHALLENGE(req, tx=1)` 发 `nonceC(32B)`
  2. 手机→相机 `OP_AUTH_CHALLENGE(rsp, tx=1)` 回 `nonceA ‖ HMAC(psk, nonceC, nonceA, "phone")`
  3. 相机→手机 `OP_AUTH_RESPONSE(req, tx=2)` 回 `HMAC(psk, nonceA, nonceC, "camera")`
  4. 手机→相机 `OP_AUTH_RESPONSE(rsp, tx=2)` 空
- **密钥派生（`KeyDerivation.kt` ↔ 相机端须对齐）**：
  ```
  developmentPsk() = hmac(ascii("SonyConnect-P1-dev-psk"), ascii("v1"))       // P1 固定预共享
  pairingKey(code, saltC) = pbkdf2(ascii(code), saltC, 20000, 32)             // 6 位码 → K_pair
  longTermKey(kPair, prekeyA, prekeyC, devIdA, devIdC) = hmac(...)            // 不过网
  commitMac(k, tag, devIdA, devIdC) = hmac(k, ascii(tag), devIdA, devIdC)
  ```
  手机端 `ascii()` 用 `s[i].code and 0xFF`；相机端 `ascii()` 用 `s.charAt(i) & 0xFF`。

### 4.4 `OP_DEVICE_INFO` JSON 契约（相机端产出 ↔ 手机端 `CameraInfo.fromDeviceInfo` 消费）

```json
{"model":"ILCE-6300","serial":"1234567","firmware":"3.10",
 "lens":"E PZ 16-50mm F3.5-5.6 OSS","batteryPct":87,"batteryRemainMin":142,
 "mode":"hotspot","ssid":"DIRECT-xxxx:ILCE-6300","name":"SonyConnect ILCE-6300"}
```
- 未知值统一 **-1**（电量 / 剩余分钟），**不要用 0**（0% 是合法电量）
- `guid/name/protoPort/filePort` **不由相机上报**，手机侧从连接上下文填
- 字段名与相机端 `DeviceInfo.java` / `SJson` 逐字对齐

### 4.5 身份与单客户端语义

- 手机端 `IdentityRepo.deviceId` = 8 字节随机（落 prefs 16 hex），`guid16()` 后补 8 零
- 相机端 `Handler.guid()` 返 8 字节，服务端 `guid16()` 补零成 16 字节 GUID
- **单客户端**：同 deviceId 新连接**踢旧**；不同 deviceId 且**正在传输 → `Init Fail(BUSY)`，绝不打断传输**

## 5. ★ 铁律与不可违反约定（任何改动不得违背）

### 5.1 用户原文（退出铁律）

> 你在写软件的退出流程时应该保证当收到退出命令进入退出流程时有序的关闭所有有关服务，
