## 三、架构与协议速查

- **FTP 2121**：只读 + REST 断点续传 + 虚拟缩略图路径 `/.sonyconnect/th|pv/<相机绝对路径>`（RETR/SIZE/150 一致性，逃逸拦截 550）
- **私有协议 TCP 2122**：UTF-8 行式 JSON，一问一答，单客户端（新连接踢旧）。命令：`HELLO{proto:1}` / `HEARTBEAT`（带 batteryPct+lens）/ `INFO`（全量设备信息+thumb 状态）/ `THUMB_BEGIN/PAUSE/RESUME/CANCEL` / `EXIT_APP`（传输完成后自动退出，相机先回包再延迟 300ms 走退出流程）
- **心跳 3s**（连续 3 次失联才判断开）/ **INFO 5s** 轮询（共用手机端 ConnectClient.ioLock 串行）
- **缩略图管线**：相机端 `ThumbnailExtractor`（通用解析法，纯 Java）+ `ThumbPrefetcher`（LRU 64）；手机端 `ThumbStore` 按需经 FTP 拉取（内存 LRU 24MB + 磁盘缓存）
- **手机端连接**：`ConnectionCenter` 状态机（未连接→扫描中→已连接）；`pinWifiNetwork()`= 找 TRANSPORT_WIFI 的 Network → 注入 FTP/协议 socketFactory + `bindProcessToNetwork`（双网防甩网，断开 unpin）；`ConnectionService` 前台保活（连接启动/断开停止）；扫描=子网 2122 心跳探测（dhcpInfo 推导，无定位权限），进软件自动扫 30s 超时报"未找到设备"；优先连接设备（型号|序列号持久化）命中自动连接
- **传输**：`DownloadService` 前台串行排空，`.part` + REST 续传；开始时 THUMB_PAUSE / 结束 THUMB_RESUME；批次进度=本批新下载字节/剩余量（断点基线不计入，进度从 0 开始）；速度/剩余 1s 采样 EMA
- **存储双通道**：`StorageSink` → `DocSink`（SAF，用户选目录）或 `FileSink`（Android/data 兜底）；`.part` 写入 + commit 原子改名
- **设置项**：下载目录（SAF）、优先连接设备、传输完成自动关闭相机客户端（默认关）、莫奈取色、深浅色
- **相机端退出链（铁律，顺序不可变）**：停 FTP（强拆会话释放 SD）→ 停 ConnectServer → [热点]关 Direct→关 WiFi→轮询确认（≤10s，后台）/ [WiFi] 若 wifiEnabledByUs 则关回 → deleteTraceFiles → APO/NORMAL → `daFinishOnly()`；`ExitCompletedReceiver` 兜底同序后 killProcess；onPause 竞速（runForcedExitCritical）毫秒级关键清理后立即 daFinishOnly
- **相机端 UI**：640×480 帧缓冲被 16:9 拉伸 → 图标/二维码预挤压 75% 宽；按键按 scanCode（MENU=514/ENTER=232/DPAD）；索尼字体真值 FsSS=26px/0.7499、FsS=28px/0.7199、FsMS=32px/0.7001、FsML=36px/0.7001；高亮=row_bg_camera(#CC3300+#DD7700 顶线)
- **SDK 兼容**：`RadioWrapperFactory`（SDK≥16→RadioWrapperJb/WifiP2pExtManager；<16→RadioWrapperGb/DirectManager）；`getRootDir()`（SDK≤10→/android/mnt/sdcard，≥16→/android/storage/sdcard0）；CameraEx/ScalarProperties 反射+try/catch 兜底

## 五、实锤过的坑（改代码前必读）

1. **通知进度条 Int 溢出**：批次总量 >2.1GB（约 86×25MB）时 `max.toInt()` 截断为负 → `coerceIn` 抛异常炸批次。已修：按比例缩放到 Int.MAX_VALUE
2. **MIUI SAF mime 规范化**：`image/x-sony-arw` 会被 MIUI 强改文件名（.part→.part.arw，堆积垃圾+rename 失败）。已修：arw 一律 `application/octet-stream`；commit/copyRename 全 runCatching
3. **DocSink Kotlin 初始化顺序**：`dirs/partDoc/finalDoc` 必须声明在 init 块**之前**（否则 init 执行时为 null → NPE → 静默回退应用目录）
4. **LazyColumn 重复 key 崩溃**：同 id 任务绝不入队两次；load() 必须 distinctBy 去重
5. **pumpToStream 的 onProgress 回调=绝对字节数**（REST 基址+已传），调用方**不得再加 base**
6. **doneBytes 结算**：必须用循环内 lastTotal（完成=size），绝不回写循环外陈旧 item
7. **stopAll 残留**：ACTION_START 必须 `stopAll=false`；FAB 状态用 `TransferStore.batchRunning`（响应式），不能用 `DownloadService.isActive()`
8. **ConnectionCenter.boundNetwork 曾从未赋值**：双网（WiFi+蜂窝）下 MIUI 甩网导致断连；现由 pinWifiNetwork 固定
9. **CancellationException 不得当业务错误上屏**（load 处 catch 需先放行）
10. **enqueue 对 DONE 重传 doneBytes=0**（.part 已提交不存在），FAILED 保留断点
11. **build-stubs.sh 必须 `-encoding UTF-8`**；相机 Java 1.6 语法限制
12. **电源拨杆竞速问题**（关机后久不能开机）：已完整分析（runForcedExitCritical 后台环/终局加固的 removeGroup/getLiveGroup 同步 await 最长 8s），修复方案曾实施后被**用户要求回退**；当前保持原行为
