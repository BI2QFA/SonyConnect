# 2026-09-05 — SonyConnect 相机端诞生（新项目，非 SonyFTP 更新）

用户决定：相机端与手机端各做一个**全新的 SonyConnect**；相机端从 SonyFTP v2.0 分叉
（旧 SonyFTP 保留在相机上共存，两者都占 2121，不可同时运行）。

## 架构总览

```
手机 SonyConnect (MD3/Kotlin)                相机 SonyConnect (bi2qfa.sony.connect)
 ├ 私有协议客户端 :2122  ◄──────────────────►  ConnectServer :2122（JSON 行，心跳/INFO/缩略图命令）
 ├ FTP 下载 :2121        ◄──────────────────►  FtpServer :2121 + 虚拟路径 /.sonyconnect/
 │                                             ├ th/<路径>  → 160x120 内嵌小图 (~6KB)
 └ 扫描 = 子网心跳探测                          └ pv/<路径>  → 1616x1080 大预览 (~0.4MB)
```

- 端口 2122 与 2121 同理固定：内核 CAP_NET_BIND_SERVICE 拒绝普通应用绑 <1024。
- 协议 v1：HELLO{proto} / HEARTBEAT / INFO / THUMB_BEGIN / THUMB_PAUSE / THUMB_RESUME /
  THUMB_CANCEL；UTF-8 行式 JSON；单客户端（新连接踢旧连接）；应答带 `rsp` 或 `error`。
- 手写 SJson（扁平 JSON 子集）替代 org.json：桌面 JDK8 可测、无依赖。

## 设备信息（型号/序列号/镜头/电量）

- **型号/序列号（原生）**：照 OpenMemories-Tweak 逆向链路——Backup 存储属性
  `model_name=0x003e0005`（≤16 字节串）、`serial_number=0x00e70003`（4 字节 hex）。
  经 OSAL 同步消息（0x3E014D）向原生 backup 守护进程读取（backup.c 原样移植）。
  链接期用空 stub libosal_uipc.so 通过链接（SONAME 命中），运行时由相机
  /system/lib/libosal_uipc.so 真库解析——已用 llvm-readelf 确认 OSAL 符号为 UND 导入。
  工具链：NDK r23c（最后支持 API16）、纯 C JNI、APP_STL=none。
- **EXIF 兜底（真样本验证出的修正）**：本机照片 **不写 0xA431 序列号**，但写
  0x010F/0x0110（Make/Model）与 **0xA434 LensModel**（样本值 "E PZ 16-50mm F3.5-5.6 OSS II"）。
  所以兜底链 = 型号✓ 镜头✓ 序列号✗（序列号只有原生路）。取"最新照片"扫描带记忆缓存。
- **镜头（实时）**：反射 CameraEx.open(0)→getLensInfo().LensName（6300fw HANDOFF 已验证配方），
  每次 open→读→release，不长持相机服务。
- **电量**：ACTION_BATTERY_CHANGED 粘性广播；剩余分钟走 didep.Power 监听（只注册一次）。
- 聚合在 DeviceInfo（native→EXIF→null 三级降级，infoSource 供关于页诊断）。

## 缩略图（ThumbnailExtractor，纯 Java 桌面可测）

规则照 ARW/JPG 交接文档：ARW=IFD0 0x0201/0x0202 大预览 + next-IFD(IFD1) 小图；
JPG=APP1 Exif→TIFF 相对偏移→IFD1 小图，大预览在尾部 512KB 找首个完整 FFD8..FFD9。
绝不硬编码偏移；II/MM 双字节序；RandomAccessFile 点读即开即关（铁律）。
FtpServer 虚拟路径拦截 `/.sonyconnect/th|pv/`（RETR/SIZE/MDTM，REST 语义一致，
逃逸回 550）；ThumbPrefetcher 有界 LRU（64 条）预取缓存经 PayloadSource 钩子挂入。

## 双连接模式

- 热点 = SonyFTP v2.0 官方状态机原样移植（5s 沉降/反射 setDirectEnabled/过滤标志/
  30s 看门狗/组就绪听广播/单次重试/失败回滚）。
- **Wi-Fi 客户端 = 完全不碰无线电**（避开启停崩溃坑）：跳系统网络设置 → 回前台轮询
  关联+DHCP IP（30s）→ 起服务。换方式 = 有序停服务 + 安静回滚无线电 + 重新启动链。

## 退出铁律（新组件融入既有顺序）

FTP stop（强拆会话释放 SD）→ ConnectServer stop（含预取线程）→ [热点模式] 同步
关 Direct → 关 WiFi → 轮询确认（≤10s）→ 恢复 APO → DAConnectionManager.finish()。
onPause 竞速分支同序（跳系统设置期间 jumpingToSystem 屏蔽强退）；ExitCompletedReceiver
兜底扩展（+ConnectServer.killActiveInstance + 预取器收尾）后 killProcess。
**Wi-Fi 模式退出不关用户自己的网络**（热点模式的 Wi-Fi 归我们接管，照关）。
